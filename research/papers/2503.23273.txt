Abstract
This paper studies the bicriteria problem of scheduling n jobs on a serial-batch
machine to minimize makespan and maximum cost simultaneously. A serial-batch
machine can process up to b jobs as a batch, where b is known as the batch
capacity. When a new batch starts, a constant setup time is required for the
machine. Within each batch, the jobs are processed sequentially, and thus the
processing time of a batch equals the sum of the processing times of its jobs. All
the jobs in a batch have the same completion time, namely, the completion time
of the batch. The main result is an O(n3 )-time algorithm which can generate
all Pareto optimal points for the bounded model (b < n) without precedence
relation. The algorithm can be modified to solve the unbounded model (b ≥
n) with strict precedence relation in O(n3 ) time as well. The results improve
the previously best known running time of O(n4 ) for both the bounded and
unbounded models.
Keywords: Scheduling, Pareto optimization, serial-batch, makespan, maximum cost

1 Introduction
Let a set of n jobs J = {J1 , J2 , . . . , Jn } and a serial-batch machine be given. Each
job Jj becomes available for processing at time zero, and has a processing time pj and
a due date dj which indicates a preferred completion time. The jobs are processed
in batches on the serial-batch machine. When a new batch starts, a constant setup
time s is required for the machine. Jobs within each batch are processed sequentially
so that the processing time of a batch equals the sum of the processing times of all
jobs in the batch. All the jobs in a batch have the same completion time, namely, the
completion time of the batch.
The serial-batch machine can process up to b jobs as a batch, where b is known as
the batch capacity. There are two models in the literature with respect to the batch
capacity b: the bounded model and the unbounded model, for which b < n and b ≥ n,
respectively.
A schedule specifies a partition of the jobs into batches and the start times of the
batches. The order of jobs within a batch is immaterial due to the definition of the job
completion times. For a given schedule σ, let Cj (σ) and Lj (σ) = Cj (σ)− dj denote the
completion time and lateness of job Jj in σ, respectively. Let Cmax (σ) = maxj Cj (σ)
and Lmax (σ) = maxj Lj (σ) denote the maximum completion time (makespan) and
maximum lateness of all jobs in σ, respectively. We omit the argument σ when it is
clear to which schedule we are referring.
The maximum lateness can be generalized to maximum cost fmax (σ) =
maxj fj (Cj (σ)), where fj (Cj (σ)) is the cost associated with job Jj . It is assumed that
all the cost functions are regular (non-decreasing in the completion times of the jobs),
and the values of fj (t) for every given time t ≥ 0 can be calculated in constant time.
In addition, there may be a precedence relation imposed on the jobs. Two types
of precedence relation are involved: (1) strict precedence relation (≺): if Ji ≺ Jj , then
Ci (σ) ≤ Sj (σ) in a feasible schedule σ; (2) weak precedence relation (): if Ji  Jj ,
then Si (σ) ≤ Sj (σ) in a feasible schedule σ.
In this paper, we study the problems of scheduling jobs, without or with precedence relations, on a serial-batch machine so as to simultaneously optimize makespan
Cmax and maximum cost fmax . The problems fall under the category of Pareto optimization scheduling (Hoogeveen, 2005; T’Kindt and Billaut, 2006). A feasible schedule
σ is Pareto optimal with respect to Cmax and fmax if there is no feasible schedule
σ ′ such that Cmax (σ ′ ) ≤ Cmax (σ) and fmax (σ ′ ) ≤ fmax (σ), where at least one of
the inequalities is strict. The objective vector (Cmax (σ), fmax (σ)) is called a Pareto
optimal point. Following the notation scheme of T’Kindt and Billaut (2006), the problems under consideration can be denoted as 1|s − batch, b < n|(Cmax , fmax ), 1| 
, s−batch, b ≥ n|(Cmax , fmax ) and 1| ≺, s−batch, b ≥ n|(Cmax , fmax ), where “s−batch”
stands for the serial-batch scheduling, “b < n” (“b ≥ n”) means that the batch
capacity is bounded (unbounded), “” (“≺”) stands for the weak (strict) precedence
relation, and the objective “(Cmax , fmax )” represents the simultaneous optimization
for criteria Cmax and fmax . Note that if jobs have different release dates, then both
1|rj |Lmax (b = 1, minimizing maximum lateness) and 1|s − batch, b ≥ n, rj |Lmax
(without precedence relation, minimizing maximum lateness) are NP-hard problems
(Brucker, 2007; Lenstra et al., 1977).

The main contribution of this paper is an O(n3 )-time algorithm for 1|s − batch, b <
n|(Cmax , fmax ) which can generate all Pareto optimal points and find a corresponding
schedule for each Pareto optimal point. The algorithm can be modified to solve 1| ≺
, s − batch, b ≥ n|(Cmax , fmax ) in O(n3 ) time as well. The two problems have the
previously best known running time of O(n4 ) (Geng et al., 2018).
The paper is organized as follows. In Section 2, the previous related studies are
reviewed. In Section 3, an O(n3 )-time algorithm for 1|s − batch, b < n|(Cmax , fmax ) is
presented. In Section 4, an O(n3 )-time algorithm for 1| ≺, s−batch, b ≥ n|(Cmax , fmax )
is presented. Finally, some concluding remarks are provided in Section 5.

2 Related work
In the last two decades, serial-batch scheduling problems have been widely investigated
(Geng et al., 2018; Baptiste, 2000; Cheng and Kovalyov, 2001; Yuan et al., 2004; Ng
et al., 2002; Webster and Baker, 1995; He et al., 2008, 2013, 2015). Along with other
results, Baptiste (2000) presented an O(n14 log n)-time algorithm for 1|s − batch, b ≥
n, rj , pj = p|Lmax and 1|s − batch, b < n, rj , pj = p|Lmax (jobs have different release
dates and equal processing times). Cheng and Kovalyov (2001) studied serial batch
scheduling problems for minimizing some regular cost functions. When the jobs have
equal release dates, they presented dynamic programming algorithms for minimizing
the maximum lateness, the number of late jobs, the total tardiness, the total weighted
completion time, and the total weighted tardiness when all due dates are equal, which
are polynomial if there is a fixed number of distinct due dates or processing times.
They also derived more efficient algorithms for some special cases, and proved the
NP-hardness of several special cases of the bounded model.
By appropriately modifying the release dates and due dates, problems 1| , s −
batch, b ≥ n, rj , pj = p|Lmax (weak precedence relation) and 1| , s − batch, b ≥
n|Lmax ( jobs have different processing times and equal release dates) can be reduced
in O(n2 ) time to 1|s − batch, b ≥ n, rj , pj = p|Lmax and 1|s − batch, b ≥ n|Lmax (Yuan
et al., 2004; Ng et al., 2002), and the latter problems can be solved in O(n14 log n)
and O(n2 ) time, respectively (Baptiste, 2000; Webster and Baker, 1995).
He et al. (2008) presented an O(n2 )-time algorithm for 1|s − batch, b ≥
n|(Cmax , Lmax ). Later, the result has been extended to an O(n5 )-time algorithm for
1|s − batch, b ≥ n|(Cmax , fmax ) (He et al., 2013). He et al. (2015) obtained an O(n6 )time algorithm for 1|s − batch, b < n|(Cmax , Lmax ). Geng et al. (2018) presented
O(n4 )-time algorithms for the problems studied in this paper, i.e., 1|s − batch, b <
n|(Cmax , fmax ) and 1| ≺, s − batch, b ≥ n|(Cmax , fmax ). They also gave an O(n2 )time algorithm for 1| , s − batch, b ≥ n|(Cmax , Lmax ), and proved that problems
1| , s − batch, b = 2|Lmax and 1| ≺, s − batch, b = 2|Lmax are strongly NP-hard.

The following definition generalizes the idea used in (Lazarev et al., 2017) for

process at most one job at a time), which plays a key role in our algorithm.
A family of (possibly empty) sets F = {J1 , J2 , . . . , Jn } is called a Candidate Set
Family (CSF for short) if these sets are disjoint, their union is J , and for i = 1, 2, . . . , n,
Ji consists of the jobs which cannot be assigned to any batch whose index is larger
than i.
The definition captures the idea of maintaining implicitly a position indicator for
each job in the algorithm. The initial CSF is {∅, ∅, . . . , J }, meaning that the jobs can
be assigned to any batches. Let us fix a particular iteration in the algorithm, a batch
and a job in this batch. We check an inequality to find whether this job is suitable
for the batch. If the inequality does not hold, then we have to move this job from
the batch into another one to its left and update the CSF accordingly. We will prove
that during the iterations the completion time of any batch will not decrease, which
implies that any job can only be moved to the left (a crucial observation in the time
complexity analysis). Therefore, when a job is accommodated into component Ji of
the current CSF, we know that this job cannot be assigned to any batch whose index
is larger than i.

In Step 1 of Algorithm AUX1, we use a Max-heap to store the jobs in Jim , i =
1, 2, . . . , n. These jobs are ordered by their processing times. A heap data structure
is an array object which can be viewed as a nearly complete binary tree (Cormen et
al., 2009). The tree is completely filled on all levels except possibly the lowest, which
is filled from the left up to a point. In a Max-heap, the value of any tree node is at
most the value of its parent. Thus, the largest element is stored at the root. The Maxheap (with τ elements) data structure is equipped with several basic procedures: (1)
MAX-HEAPIFY, running in O(log τ ) time, is the key to maintaining the Max-heap
property; (2) BUILD-MAX-HEAP, running in O(τ ) time, produces a Max-heap from
an unordered input array; (3) MAX-HEAP-INSERT, running in O(log τ ) time, inserts
an element into the Max-heap; (4) MAX-HEAP-EXTRACT, running in O(log τ ) time,
gets the maximum element and delete it from the Max-heap.
Step 1 of AUX1 can be implemented in O(n) time (BUILD-MAX-HEAP). Step
2 can be implemented in O(n log n) time in each iteration (MAX-HEAPIFY, MAXHEAP-INSERT and MAX-HEAP-EXTRACT). Steps 3 and 5 require O(n) time in
each iteration.
In Step 4, each job deletion (can be accomplished via MAX-HEAPIFY) or insertion
(MAX-HEAP-INSERT) requires O(log n) time. Since there are n jobs and each job
goes through at
Pmost n − 1 sets (from Jn to J1 ), the total number of job deletion and

the inequalities for all jobs in one iteration requires O(n) time. Hence, the complexity
contribution of Step 4 for all iterations is O(n3 ).
The overall running time of Algorithm AUX1 is O(n3 log n), which is determined

5 Conclusions
In this paper we investigated the bicriteria problem of scheduling jobs on a serial-batch
machine to minimize makespan and maximum cost simultaneously. We improved the
earlier results by presenting O(n3 )-time algorithms for the bounded model without
precedence relation and the unbounded model with strict precedence relation. For
13

It is also interesting to improve the algorithms presented in (Baptiste, 2000) for the
problem of scheduling jobs with equal processing times and unequal release dates on
a serial-batch machine.
